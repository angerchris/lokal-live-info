# lokal.live – Projektinformation

Aktuelle Informationen per WhatsApp online bringen – nach ausdrücklicher Bestätigung des Betriebs.

Diese statische Seite stellt lokal.live und seinen Gründer Christopher Angerer vor. Mehr zum Produkt: https://www.lokallive.de/fuer-betriebe

## Aufbau

`index.html` enthält CSS und unveränderte Originalbilder vollständig. Kein Build, keine externen Skripte, Schriftdateien oder Tracker. `.nojekyll` ermöglicht die direkte Ausgabe durch GitHub Pages. Veröffentlichung aus `main`, Ordner `/`.

## Abnahme

Am 12.10.2026 bestätigte Christopher die korrekte Portraitdarstellung sowie 200%-Zoom und NVDA für die lokale Fassung. HTML-Struktur, eingebettetes Originalportrait und externe Linkziele wurden geprüft. Die Veröffentlichung ist ausdrücklich freigegeben; die Veröffentlichungsfassung verwendet `index,follow`. Die Website-Links sind normale HTML-Links ohne `nofollow`.
